# Ecommerce-Analytics
Analyzed transactional data to give insights on revenue trends, customer behavior, and churn patterns using Python, SQL and Power BI.

⚙️ Tech Stack
SQL (MySQL)
Python (Pandas)
Power BI

📈 Key Insights
Peak orders occur in evening hours
Top customers contribute to majority of the revenue
Repeat customers generate higher value
Noticeable churn among low-value users
